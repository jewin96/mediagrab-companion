# MediaGrab Companion

Windows helper for the [MediaGrab Firefox add-on](https://addons.mozilla.org/en-US/firefox/addon/mediagrab-stream-downloader/).

1. Download the ZIP from the [latest release](https://github.com/jewin96/mediagrab-companion/releases/latest).
2. Extract it and run **Install-Companion.cmd**.
3. Restart Firefox and open MediaGrab.

Windows 10/11, 64-bit. If the companion does not connect, run **Diagnose-Companion.cmd**.
